ABHITOOLS PHASE 22 — SETTINGS & BUSINESS RULES CENTER
Build date: 2026-08-24
Release: V2.1.0 Stable

WHAT WAS ADDED
- Admin Settings & Business Rules Center.
- Server-synced app_settings stored in Supabase.
- Business display name and WhatsApp signature settings.
- Default payment method.
- Configurable reminder window (1–14 days) and default reminder view.
- Admin layout / Command Center defaults with explicit apply-to-device action.
- Editable WhatsApp due, overdue, payment and closing templates with safe placeholders and live preview.
- Settings update/reset Activity History events.
- Typed RESET SETTINGS flow; automatic safety snapshot before reset.
- Backup format v6 includes app_settings in server snapshots and Full JSON export.
- v5 restore compatibility: old snapshots preserve current app settings.

ARCHITECTURE
- No new standalone Vercel API function.
- Settings route: /api/dashboard?mode=settings
- New server modules: server_routes/settings.js, server_routes/settings_config.js
- Vercel api/*.js count remains 12.

SUPABASE MIGRATIONS
- phase22_app_settings
- phase22_backup_v6_settings

SAFETY
- Existing borrower/loan/EMI amounts and dates are not modified by the migration.
- Legacy dates are still never guessed automatically.
- Secrets are not stored in source or app settings.
